# 📋 CORE FUNCTIONALITY

## What STARTOS Does (3-Step Flow)

```
USER INPUT → SEARCH → VERIFY → DISPLAY VERDICT
```

### Step 1: User Input
- User pastes viral claim/WhatsApp forward
- Example: "BMRCL shutting Purple Line on Tuesday"

### Step 2: Retrieval (Elasticsearch)
- Search indexed civic sources
- Return top 5 relevant documents
- Sources: BMRCL, BBMP, BWSSB, news archives

### Step 3: Verification (AWS Bedrock)
- Analyze claim vs. evidence
- Generate authenticity score
- Provide reasoning with citations

### Step 4: Display
- Show verdict (VERIFIED/MISLEADING/FALSE/INSUFFICIENT)
- Display authenticity score (0-100%)
- List evidence reasoning
- Cite trusted sources

CLAIM TO VERIFY:

EVIDENCE FROM TRUSTED SOURCES:
{evidence}

# 🔧 ELASTICSEARCH INDEX SETUP

## Index Configuration
```json
{
  "settings": {
    "number_of_shards": 1,
    "number_of_replicas": 0,
    "analysis": {
      "analyzer": {
        "civic_analyzer": {
          "type": "standard",
          "stopwords": "_english_"
        }
      }
    }
  },
  "mappings": {
    "properties": {
      "source": {"type": "keyword"},
      "text": {"type": "text", "analyzer": "civic_analyzer"},
      "date": {"type": "date"},
      "url": {"type": "keyword"},
      "category": {"type": "keyword"}
    }
  }
}
```

## Search Query Template
```python
{
    "query": {
        "multi_match": {
            "query": claim,
            "fields": ["text^2", "source"],
            "type": "best_fields",
            "fuzziness": "AUTO"
        }
    },
    "size": 5,
    "sort": [
        {"_score": "desc"},
        {"date": "desc"}
    ]
}
```
